## Описание репозитория:
**Homework_1 - Калькулятор**  
Реализация калькулятора четырьмя различными способами: линейное выполнение, функциональное разделение, циклическая обработка ввода и объектно-ориентированный подход. Демонстрация различных архитектурных подходов к решению одной задачи.   
  
**Homework_2 - Строки**  
Программа из пяти уровней для практики обработки строк. Включает операции изменения регистра, поиска и замены символов. Финальный уровень содержит функцию автоматической коррекции текста: удаление лишних пробелов и исправление пунктуации.  
  
**Homework_3 - Лабиринт**  
Текстовая игра с системой комнат, инвентаря и предметов. Реализованы механики: постепенное открытие карты, сбор и использование предметов, комбинирование объектов, система здоровья. В коде показано различие между обычным копированием и глубоким копированием списков.
  
**Homework_4 - Титаник**  
Обработка датасета с использованием Pandas и NumPy. Включает загрузку данных, анализ структуры, заполнение пропусков медианными значениями, фильтрацию по условиям и группировку данных. Результат — статистика выживаемости и сохранение обработанных данных в CSV.
